# Library Management System

A console-based Library Management System developed using Java as part of the CodeNova Java Programming Internship.

## Features

- Add new books
- View all books
- Search books by ID
- Issue books
- Return books
- Track book availability
- Save and load book records using CSV files
- Prevent duplicate book IDs
- Validate book details

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Collections
- File Handling
- CSV Data Storage

## How to Run

1. Install the Java Development Kit (JDK).
2. Open this project folder in VS Code.
3. Open the terminal in the project folder.
4. Compile the Java files:

   `javac Book.java Main.java`

5. Run the application:

   `java Main`

## Project Files

- `Book.java` — Stores book details and availability status.
- `Main.java` — Contains the menu and library operations.
- `books.csv` — Stores book records.
